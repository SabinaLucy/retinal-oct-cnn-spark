
# Retinal OCT Disease Classification Using CNN and Apache Spark

## Project Overview
This project uses a Convolutional Neural Network (CNN) to classify retinal OCT images into four categories: CNV, DME, DRUSEN, and NORMAL.

We will use Apache Spark for data processing, exploratory data analysis, and patient level data splitting. TensorFlow and Keras will be used to train and evaluate the CNN.

## Research Questions
1. How does patient level splitting compare with random image splitting?
2. Which retinal disease classes are most difficult for the CNN to classify?
3. How does image resolution affect classification performance?

## Dataset
We will use the Retinal OCT dataset available on [Kaggle](https://www.kaggle.com/datasets/paultimothymooney/kermany2018).

The original dataset is available on [Mendeley Data](https://data.mendeley.com/datasets/rscbjbr9sj/3).
